## Policy Summary

All AI systems are internal implementation tools only. They receive no authorship, attribution, branding, or identity exposure unless explicitly required by law or when a human directly asks if AI was used.

## Prohibited Patterns (Now Blocked)

The commit-msg hook blocks these patterns:
- `Co-authored-by:`
- `Generated-by:`
- `AI-generated` (in attribution context)
- `Created with`
- `Assisted by`
- `Written by.*AI`
- Provider names: `OpenAI`, `Claude`, `GPT-`, `Copilot`, `Cursor`, `ChatGPT`, `Gemini`, `Anthropic`

## Developer Guidelines

### ✅ Compliant Commit Message

```
fix: update certificate eligibility logic

What:
- Make final exam requirement conditional
- Only check quizzes if course has quiz policy

Why:
- Simple courses should issue certificates without exams
- Previous logic incorrectly required exams for all courses

Impact:
- Users can now get certificates for completed 1-day courses
- Certificate page shows "Valid Certificate" correctly
```

### ❌ Non-Compliant Commit Message

```
fix: update certificate eligibility logic

Fixed the bug where certificates weren't working.

Co-authored-by: Claude <ai@anthropic.com>
Generated-by: Cursor AI
```

## Maintenance

### Regular Audits

Run periodic audits to catch violations:

```bash
# Check for prohibited patterns in recent commits
git log --oneline -20 --format="%s%n%b" | grep -iE "Co-authored-by|Generated-by|OpenAI|Claude|GPT|Copilot"

# Check source files for AI attribution comments
rg "Generated by|Created with|AI-generated|// via|// Added by" app/ scripts/ --type ts --type tsx
```

### When Violations Found

1. **In uncommitted files**: Remove attribution before commit
2. **In recent unpushed commits**: Amend or rebase to remove
3. **In pushed commits**: Document as immutable, ensure no future violations
4. **In source files**: Remove and commit fix
